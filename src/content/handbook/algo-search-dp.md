## 本篇只解决这 1 类问题

当问题不再有直接的线性或图最短路套路，而是面临“成千上万种组合选哪组最好”“局部选最优到底会不会错过全局最优”“状态之间互相依赖怎么不重复算”时，就需要算法设计的三大压轴范式：**回溯搜索、贪心算法与动态规划（DP）**。本篇彻底打通 **`ALG-43` ~ `ALG-50`**，并保留底层验证程序与 0/1 背包正倒序手算对照。

## 详细教程：ALG-43 ~ ALG-50

### 一、回溯搜索框架：排列、组合、子集与去重剪枝（ALG-43）

回溯的本质是在一棵隐式**决策树**上跑 DFS。写所有回溯题先背下这个三步铁骨架：**做选择 → 递归下一层 → 撤销选择**。

```text
回溯决策树片段 (从 [1,2,3,4] 选 2 个):
start=0: 选 1 ──▶ start=1: 选 2 → [1,2] (撤销 2) / 选 3 → [1,3] / 选 4 → [1,4]
         (撤销 1)
         选 2 ──▶ start=2: 选 3 → [2,3] / 选 4 → [2,4]
         选 3 ──▶ start=3: 选 4 → [3,4]
         选 4 ──▶ 剩余 0 个不够再选 1 个 → 剪枝返回！
```

| 题型差异 | 控制去重与顺序的开关 | 同层重复元素怎么去重？（关键！） |
| --- | --- | --- |
| **子集 / 组合** | 传下标 **`start`**，下一层传 `i + 1`（防止 `[1,2]` 和 `[2,1]` 重复） | 先排序！`if (i > start && nums[i] == nums[i - 1]) continue;` |
| **排列** | 传布尔数组 **`used[n]`**（因为 `[1,2]` 和 `[2,1]` 算不同排列） | 先排序！`if (i > 0 && nums[i] == nums[i-1] && !used[i-1]) continue;` |
| **可重复选同一元素** | 组合传 **`i`**（不加 1）即可无限选 | 必须控制单层求和上限 + 排序剪枝防死循环 |

### 二、搜索加速：N 皇后棋盘剪枝、双向 BFS 与启发式 A*（ALG-44）

1. **N 皇后 / 数独约束传播**：不要等全部摆满再校验冲突！每次放子用三个小布尔/位掩码标记“当前列 `col`、主对角线 `row - col + n`、副对角线 `row + col`”是否已被占，冲突瞬间 `continue` 剪枝。
2. **双向 BFS（指数搜索变半截树）**：如果起点和终点都明确（如单词接龙每次改 1 个字母），从起点搜 10 步可能展开 $b^{10}$ 个节点；改为**从起点和终点轮流扩展，每次挑较小一端队列向前推进 1 层**，节点数骤降为 $2 \times b^5$（在分支因子 `b=10` 时从百亿降到十万！）。
3. **A* 启发式搜索**：在 Dijkstra 的基础上把小顶堆排序优先级改成 $f(n) = g(n) + h(n)$，其中 $g(n)$ 是起点到 $n$ 的已走真实代价，$h(n)$ 是估计到终点的下界距离（如网格曼哈顿距离）。只要 $h(n)$ **不高估真实距离（可采纳性）**，就能保证找到最短路且大幅减少无效探路！

### 三、贪心算法与交换论证：什么时候能贪，什么时候必翻车？（ALG-45）

贪心就是“每一步只看眼前最爽的选择”，因此它**极容易写错**！检验一个贪心对不对只有两个手段：要么用**交换论证**证明最优，要么用小输入**找一个反例**：
- **能用贪心（区间最多不重叠个数）**：按**结束时间最早**排序依次挑选。*交换论证*：假设最优解第 1 个选的结束更晚，把它硬替换成结束最早的那个，不仅个数没少，后面留下的空间还更大！
- **贪心翻车反例（带权最大区间和）**：把 `[0,2)` 权 `1`、`[2,4)` 权 `1`、`[0,4)` 权 `9` 喂给同一按结束时间排序的贪心规则，它会挑前两个只赚 `2`，漏掉最优解 `9`！带权区间必须老老实实用 DP。
- **常见正确贪心模型**：Huffman 哈夫曼最优编码树（每次合并频次最小两棵树）、跳跃游戏（实时维护能跳到的最远右边界）、分发饼干与任务调度。

### 四、动态规划（DP）心智模型与四步推演法（ALG-46）

为什么暴搜会超时？因为很多分支走到了**一模一样的子状态**反复重算。**记忆化搜索（自顶向下递归 + 缓存）** 与 **递推填表 DP（自底向上循环）** 本质完全等价，都要满足三大条件：**最优子结构、无后效性、重叠子问题**。

写任何 DP 严格按四步走，绝不凭空猜公式：
1. **定义 `dp` 状态与下标含义**：一维还是二维？下标表示“前 `i` 个元素”还是“以 `i` 结尾”？含义写不清后面必崩！
2. **推导出状态转移方程**：站在当前状态 `dp[i]`，问自己“最后一步是怎么跨过来的？”把所有合法来源取 `min`/`max` 或求和。
3. **确定初始条件 `Base Case` 与非法哨兵值**：求最小值初始化 `+INF`、求最大值初始化 `-INF` 或 `0`、方案数初始化 `1`（空方案 1 种）。
4. **确定遍历顺序与暴力对比验证**：永远保证计算 `dp[cur]` 时它依赖的格子**已经被算好了**；初学时务必写个 10 行暴力递归在小规模输入上逐一核对！

### 五、一维线性 DP：打家劫舍、Kadane 与 LIS 二分 $\mathcal{O}(n \log n)$（ALG-47）

| 经典模型 | 状态定义 | 核心转移方程 | 复杂度 |
| --- | --- | --- | --- |
| **打家劫舍** | `dp[i]`：前 `i` 家最大偷窃额 | `dp[i] = max(dp[i-1], dp[i-2] + nums[i])` | $\mathcal{O}(n)$ 滚动两个变量 |
| **最大子数组和（Kadane）** | `cur`：**以当前位置结尾**的最大子段和 | `cur = max(x, cur + x); best = max(best, cur);` | $\mathcal{O}(n)$，极简且全负也对 |
| **最长递增子序列（LIS）** | `dp[i]`：以 `a[i]` 结尾的最长严格上升子序列长 | $\mathcal{O}(n^2)$ 枚举前面 `< a[i]` 的最大值加 1 | $\mathcal{O}(n \log n)$ 技巧：维护 `tails[len]` 数组存长度为 `len+1` 的最小结尾值，用 `lower_bound` 原地替换！ |

### 六、背包问题全家族：0-1 背包与完全背包正逆序奥秘（ALG-48）

1. **0-1 背包（每件物品最多选 1 次）**：
   - `dp[c]` 表示容量不超过 `c` 时的最大价值。
   - **空间压缩铁律：内层容量必须从大到小倒序枚举 `for (int c = cap; c >= w[i]; --c)`**！因为倒序保证了读取 `dp[c - w[i]]` 时，里面的数还是“上一轮没放过当前物品 `i`”的旧值。
2. **完全背包（每件物品可无限次选）**：
   - **内层容量从小到大正序枚举 `for (int c = w[i]; c <= cap; ++c)`**！正序允许你刚把 `i` 放进更小容量里，随后更大容量立刻在它的基础上再多加一件 `i`！
3. **组合数 vs 排列数循环顺序坑（零钱兑换 II vs 爬楼梯求组合）**：
   - 求**组合数**（顺序无关，`1+2` 与 `2+1` 算 1 种）：**外层枚举物品，内层正序枚举容量**！
   - 求**排列数**（顺序有关，`1+2` 与 `2+1` 算 2 种）：**外层正序枚举容量，内层枚举所有物品**！

### 七、二维网格与双串 DP：LCS 最长公共子序列与编辑距离（ALG-49）

面对两个字符串 `s`（长 $n$）和 `t`（长 $m$），几乎所有问题统一设 **`dp[i][j]` 表示前缀 `s[0..i-1]` 与 `t[0..j-1]` 的答案**（强烈推荐多开一行一列 `dp[0][*]` 和 `dp[*][0]` 处理空串边界！）：

- **最长公共子序列（LCS）**：
  - 若 `s[i-1] == t[j-1]`：`dp[i][j] = dp[i-1][j-1] + 1`（尾部刚好配对，白捡长度 +1）；
  - 否则：`dp[i][j] = max(dp[i-1][j], dp[i][j-1])`（丢掉其中一个的末尾）。
- **编辑距离（Levenshtein Distance）**：把 `s` 变成 `t` 最少需要几步插入/删除/替换？
  - 边界：`dp[i][0] = i`（全删光），`dp[0][j] = j`（全插入）；
  - 若 `s[i-1] == t[j-1]`：`dp[i][j] = dp[i-1][j-1]`（零代价直接过）；
  - 否则取三种编辑方案最小值：`1 + min({ dp[i-1][j], dp[i][j-1], dp[i-1][j-1] })`（分别对应删 `s` 字符、插 `t` 字符、替换成一样）。

### 八、高阶 DP 模式：状态机 DP、区间 DP 与树形 DP（ALG-50）

1. **状态机 DP（股票买卖系列通解）**：每天结束时把你的状态显式建为节点：`hold`（手里持股）、`cash`（空仓可买）、`cooldown`（刚卖出冷静期）。写清楚每个状态当天能怎么跳转，哪怕加手续费、限交易 $K$ 次或含冷却期，转移方程都能照图直译！
2. **区间 DP（戳气球 / 石子合并 / 回文子串）**：把区间长度 `len` 从 `2` 到 `n` 从小到大铺开（**必须按长度由短到长递推！**），枚举区间左右端点 `[l, r]` 及中间分割点 `k`，合并左右两个更短区间的最优解。
3. **树形 DP（树上最大独立集 / 树的直径）**：在树的后序遍历中自底向上收集每个子节点返回的两个值（如 `pair<选当前节点, 不选当前节点>`，代表打家劫舍 III），父节点用孩子返回值算完再往上传，仅需 $\mathcal{O}(n)$！

## 关键步骤追踪表

### 追踪 1：Kahn 拓扑排序处理 CMake 依赖（`0->1, 0->2, 1->2`）

| 步骤 | 当前队列 | 弹出节点 `u` | 更新后的 `indeg` (`[0,1,2]`) | 已输出 `order` |
| --- | --- | --- | --- | --- |
| 初始化 | `[0]` | — | `[0, 1, 2]` | `[]` |
| 第 1 步 | `[]` | `0` (`core`) | `[0, 0, 1]`（`1` 归零入队） | `[0]` |
| 第 2 步 | `[1]` | `1` (`cli`) | `[0, 0, 0]`（`2` 归零入队） | `[0, 1]` |
| 第 3 步 | `[2]` | `2` (`tests`) | `[0, 0, 0]` | `[0, 1, 2]` |

若再加一条反向依赖 `2 -> 0`，初始 `indeg` 变成 `[1, 1, 2]`，队列一开始就为空，`order.size() == 0 != 3`，立刻报告循环依赖。

### 追踪 2：`dijkstra` 在 `A(0)->B(1):3, A(0)->C(2):1, C(2)->B(1):1` 上的执行过程

| 弹出小顶堆 `(d, u)` | `d > dist[u]`? | 松弛邻边后更新的 `dist` (`[A,B,C]`) | 新入堆状态 |
| --- | --- | --- | --- |
| 初始化 | — | `[0, INF, INF]` | `(0, A)` |
| `(0, A)` | 否 | `dist[B]=3`, `dist[C]=1` → `[0, 3, 1]` | `(3, B)`, `(1, C)` |
| `(1, C)` | 否 | 经 `C` 到 `B` 代价 `1+1=2 < 3`，更新 `dist[B]=2` → `[0, 2, 1]` | `(2, B)` |
| `(2, B)` | 否 | `B` 无出边，确认 `dist[B]=2` | — |
| `(3, B)` | **是 (`3 > 2`)** | **懒惰删除直接跳过**，不会破坏已求出的最优解 `2` | — |

### 追踪 3：为什么 0/1 背包 1D 数组必须**倒序**？（单物品 `w=2, v=3`，`cap=4`）

| 写法 | 遍历顺序 | `dp[0..4]` 初始 | `c=2` 更新后 | `c=4` 更新后 | 结果对吗？ |
| --- | --- | --- | --- | --- | --- |
| **正确：倒序** | `c = 4 → 3 → 2` | `[0,0,0,0,0]` | `dp[4]` 先算时 `dp[2]` 还是 `0`，故 `dp[4]=3` | 最后算 `dp[2]=3` | **`3`（正确，只选 1 次）** |
| **错误：正序** | `c = 2 → 3 → 4` | `[0,0,0,0,0]` | 先把 `dp[2]` 改成了 `3` | `dp[4] = dp[2] + 3 = 6` | **`6`（错误，同件选了 2 次）** |

## 1 行反例坑点速查表

| 常见误区 | 1 行反例 / 症状 | 正确做法 |
| --- | --- | --- |
| BFS 出队时才标记 `visited` | 菱形图 `A→B, A→C, B→D, C→D`：`D` 被 `B` 和 `C` 重复入队两次，网格图直接指数爆炸 | 在把 `v` 推进队列的**同一瞬间**更新 `dist[v]` / `visited[v]` |
| 拓扑排序漏查 `order.size() == V` | 图有环时入度不为 0 的节点永不入队，函数默默返回残缺序列 | 必须校验 `order.size() == adj.size()`，不等即显式报告环 |
| 对带负权图直接跑 Dijkstra | `A→B(3), A→C(5), C→B(-4)`：Dijkstra 先弹出 `B(3)` 后不再更新它，错过 `5-4=1` | 有负权边改用 Bellman–Ford 或 SPFA，并检测可达负环 |
| 拿无权区间贪心套带权区间 | `[0,2) w=1, [2,4) w=1, [0,4) w=9`：按结束时间贪心得 `2`，错失 `9` | 带权区间调度应按结束时间排序后用 DP + 二分查找前置相容区间 |
| 0/1 背包 1D 滚动写成正序 `c++` | 单件 `(w=2, v=3)` 在 `cap=4` 下算出 `6` | 0/1 背包倒序 `for (int c = cap; c >= w[i]; --c)`；完全背包才正序 |

## 4 个微练习

### 练习 1（`ALG-09` BST 结构与高度）

如果把 `algo-graphs-dp.cpp` 中插入 BST 的序列改成已经排好序的 `{1, 2, 3, 4, 6}`，树的高度是多少？和 `{4, 2, 6, 1, 3}` 比，每次查找最坏要走几步？

<details>
<summary>提示与参考答案</summary>

按 `{1, 2, 3, 4, 6}` 依次插入会退化成全向右斜的链，树高（按节点数计）为 `5`，查找 `6` 要比较 `5` 次；而 `{4, 2, 6, 1, 3}` 的高度只有 `3`，最坏比较 `3` 次。

</details>

### 练习 2（`ALG-10` BFS 层序与不可达）

在 `ugraph` 中增加第 5 个节点 `4`（边为 `3-4`），保留 `0-1-2` 不变。从节点 `0` 出发跑 `bfs_distances`，输出数组是什么？如果在全图上统计连通分量个数，共有几个分量？

<details>
<summary>提示与参考答案</summary>

从 `0` 出发只能到达 `0, 1, 2`，节点 `3` 和 `4` 不可达，因此距离数组为 `{0, 1, 2, -1, -1}`。做全图遍历时，以未访问节点为起点分别启动搜索，`{0,1,2}` 与 `{3,4}` 共构成 **2** 个连通分量。

</details>

### 练习 3（`ALG-11` Kruskal 选边与并查集）

在 `algo-graphs-dp.cpp` 的 `kruskal_mst` 输入中，3 条无向边按权重排序后依次为 `(0,2,1)`、`(1,2,1)`、`(0,1,3)`。请追踪每次调用 `dsu.unite` 的返回值，为什么第 3 条边被跳过了？

<details>
<summary>提示与参考答案</summary>

1. 处理 `(0,2,1)`：`find(0) != find(2)`，合并成功返回 `true`，`total = 1`。
2. 处理 `(1,2,1)`：`find(1) != find(2)`，合并成功返回 `true`，`total = 2`。
3. 处理 `(0,1,3)`：此时 `0`、`1`、`2` 已经在同一集合，`find(0) == find(1)`，`unite` 返回 `false`（跳过，避免成环），最终总权为 `2`。

</details>

### 练习 4（`ALG-15` 0/1 背包与选法恢复）

在 `algo-graphs-dp.cpp` 的 `knapsack_2d` 里，对于 `weights={2,3,4,5}, values={3,4,5,8}, cap=7`，最优价值 `11` 是由哪几件物品凑出来的？提示：从 `dp[n][cap]` 倒推回 `i = 1`。

<details>
<summary>提示与参考答案</summary>

如果只需要求最优值，1D 滚动数组最省空间；若需要**恢复具体选了哪几件物品**，保留 2D `dp` 表最直接：若 `dp[i][c] != dp[i-1][c]`，说明选了第 `i` 件物品（下标 `i-1`），随后把 `c` 减去 `w[i-1]` 继续往上推。对 `cap=7`：选了重量 `2`（价值 `3`）和重量 `5`（价值 `8`），总重 `2+5=7`，总价值 `3+8=11`。

</details>
