## 本篇总览（ALG-01 ~ ALG-08）

很多初学者一听到“数据结构与算法”就头疼——好像满篇都是 $\mathcal{O}(n \log n)$、指针和数学证明。其实它的本质超级接地气：**同样是存 10 万条日志，摆法不同（数据结构），找起来和改起来的方法不同（算法），耗时能差出成千上万倍！**

本篇覆盖算法学习的第 1 块基石（对应 `ALG-01` ~ `ALG-08`）：先建立 5 种高频结构的直观模型并跑通对比程序，再系统掌握大 O 复杂度、空间/均摊代价、循环不变量、前缀和、差分与位运算。

## 一、生活比喻看懂 5 种基本数据结构（ALG-01）

| 名称 | 生活比喻 | 擅长干嘛（快） | 不擅长干嘛（慢） | C++ 常用名字 |
| --- | --- | --- | --- | --- |
| **数组 / 动态数组** | **连在一起的编号快递柜**（0 号、1 号、2 号…） | 知道柜号（下标），**1 秒直达**；往队尾放最快 | 在正中间硬塞一个新柜子，后面所有人都得往后挪 | `std::vector` / `std::array` |
| **链表** | **寻宝游戏纸条**（第 1 张纸条写着第 2 张藏哪） | 拿到纸条就能原地插入/撕掉，不用挪别人 | 想找第 500 个？只能从第 1 张一路摸过去 | `std::list` / `Node*` |
| **栈（Stack）** | **食堂叠盘子**（后放上去的盘子最先拿走，LIFO） | 只管最顶上那个（函数调用栈、撤销 Ctrl+Z） | 想拿最底下那个，必须先把上面的全拿开 | `std::stack` |
| **队列（Queue）** | **奶茶店排队**（先排队的先买到，FIFO） | 严格按先来后到处理任务（线程池任务队列） | 不能随便插队 | `std::queue` |
| **哈希表** | **贴了名字标签的储物柜**（算一下名字直接开柜） | 知道名字（如 `"ERROR"`），平均 **1 步找到** | 柜子里的东西没有顺序，没法按大小排好打印 | `std::unordered_map` |

## 二、数步数、渐近记号与 1 秒运算量估算（ALG-02）

时间复杂度不测量“跑了多少毫秒”（不同 CPU、是否开 `-O2` 耗时差异巨大），而是测量**当输入规模 $n$ 不断变大时，核心基本操作次数 $T(n)$ 的增长趋势**。

### 1. 常见渐近记号辨析

- **$\mathcal{O}(g(n))$（上界 / Big-O）**：最坏也不超过这个增长量级，工程口头交流最常用（“最多这么慢”）。
- **$\Omega(g(n))$（下界 / Big-Omega）**：至少要这么多步（“再优化也快不过这个底线”，例如基于比较的排序下界是 $\Omega(n \log n)$）。
- **$\Theta(g(n))$（紧确界 / Big-Theta）**：上界和下界同阶，例如双层循环 `for (i = 0..n-1) for (j = 0..i-1)` 执行次数严格等于 $\frac{n(n-1)}{2}$，就是精确的 $\Theta(n^2)$。

### 2. 常见复杂度量级与“1 秒天花板”速查

现代 CPU 单核每秒大约能执行 **$10^7 \sim 10^8$ 次** 简单基本操作（比较、加减、数组下标访存）。拿到一道题看到 $n$ 的数据范围，不用写代码就能立刻反推出允许的最慢复杂度：

| 复杂度 | $n=1000$ 步数 | $n=10^5$ 步数 | 1 秒内最大承受的 $n$ | 典型代码特征 |
| --- | --- | --- | --- | --- |
| $\mathcal{O}(1)$ | $1$ | $1$ | 无穷大 | 哈希直接访问、数学公式直算 |
| $\mathcal{O}(\log n)$ | $\approx 10$ | $\approx 17$ | $10^{18}$ 以上 | 每次把规模砍半（二分、快速幂） |
| $\mathcal{O}(\sqrt{n})$ | $\approx 32$ | $\approx 316$ | $10^{14}$ | 试除法判断素数、分块 |
| $\mathcal{O}(n)$ | $1000$ | $10^5$ | $10^7 \sim 10^8$ | 单层扫描、双指针、单调栈/队列 |
| $\mathcal{O}(n \log n)$ | $\approx 10^4$ | $\approx 1.7 \times 10^6$ | $10^6$ | 排序、`map`/堆操作、分治 |
| $\mathcal{O}(n^2)$ | $10^6$ | $10^{10}$（**超时！**） | $5000 \sim 10^4$ | 两重嵌套循环、区间 DP |
| $\mathcal{O}(2^n)$ / $\mathcal{O}(n!)$ | 直接爆炸 | 宇宙毁灭算不完 | $n \le 20$ / $n \le 11$ | 暴搜子集/全排列回溯 |

> **新手常踩坑**：看到代码里有两层循环就脱口而出 $\mathcal{O}(n^2)$！错！要看**内层变量总共走了多少次**：
> - 滑动窗口中 `right` 走 $n$ 步，`left` 总体也只走 $n$ 步，外层 `for` + 内层 `while` 总计才 $2n$ 步，实际是 **$\mathcal{O}(n)$**！
> - 调和级数循环 `for (i=1; i<=n; ++i) for (j=i; j<=n; j+=i)` 总步数是 $n(1 + 1/2 + 1/3 + \dots + 1/n) \approx n \ln n$，属于 **$\mathcal{O}(n \log n)$**！

## 三、空间复杂度、递归栈隐性开销与时间换空间（ALG-03）

**额外空间复杂度（Auxiliary Space）** 统计的是除了输入数据本身以外，算法**额外申请**的容器和**调用栈深度**。

```cpp
// 示例 A：空间 O(1) — 只用了几个局部变量
int sum_iter(const std::vector<int>& a) {
    int total = 0;
    for (int x : a) total += x;
    return total;
}

// 示例 B：空间 O(n) — 千万别忽略递归调用栈！
long long fact_rec(int n) {
    if (n <= 1) return 1;
    return n * fact_rec(n - 1); // 压栈 n 层栈帧，n=10^6 时可能直接 Stack Overflow!
}
```

### 常见空间估算基准（C++ 64 位环境）
- 1 个 `int` = 4 字节；`10^6` 个 `int` ≈ **4 MB**；`10^7` 个 `int` ≈ **40 MB**。
- 在线评测/服务通常限制堆栈：Linux 默认线程栈只有 **8 MB**（Windows MinGW 默认仅 **1~2 MB**），递归深度一旦超过 $5 \times 10^4 \sim 10^5$ 就极易爆栈，此时必须改写成迭代或显式 `std::vector` 栈。
- **工程权衡**：经典“空间换时间”（如哈希表缓存、前缀和数组）用几 MB 内存把 $\mathcal{O}(n^2)$ 降成 $\mathcal{O}(n)$；反之遇到流式海量数据只能用“时间/近似换空间”（如小顶堆维护 Top-K 只占 $\mathcal{O}(K)$ 内存）。

## 四、均摊分析与 `std::vector` 倍增扩容证明（ALG-04）

有人疑惑：`std::vector::push_back` 容量满了要分配 2 倍新数组、把旧元素全拷贝一遍，单次最坏明明是 $\mathcal{O}(n)$，为什么教材都说尾插是 $\mathcal{O}(1)$？这就叫**均摊复杂度（Amortized $\mathcal{O}(1)$）**。

### 用“存钱罐（记账法）”一秒证完

假设每次 `push_back` 时，规定你往存钱罐存入 **3 枚硬币**：
- 1 枚立刻花掉：把新元素放进当前末尾空位。
- 2 枚存进存钱罐，专门留给将来扩容时搬运旧元素。

看看容量从 $C$ 扩到 $2C$ 时存了多少钱：
1. 上一次刚从 $C/2$ 扩到 $C$ 时，前 $C/2$ 个格子已满，后半段 $C/2$ 个空位每填进 1 个新元素，就往罐子里净存 **2 枚硬币**；
2. 等这 $C/2$ 个空位也填满、总共塞了 $C$ 个元素触发下次扩容时，罐子里刚好攒了 **$(C/2) \times 2 = C$ 枚硬币**！
3. 把这 $C$ 个元素搬到新数组正好需要 $C$ 枚硬币——一分不差！

所以连续插入 $n$ 次，总开销绝对不超过 $3n$，平均每次插入严格是 **$\mathcal{O}(1)$**！

> **对比坑**：如果每次扩容不是“翻倍（$\times 2$）”而是“每次只多开 10 个格子（$+10$）”，那么每插 10 个就要搬 $10, 20, 30, \dots, n$ 次，总代价变成 $\Theta(n^2)$，均摊就退化成 $\mathcal{O}(n)$！这就是所有现代动态数组都采用**等比扩容（$\times 1.5$ 或 $\times 2$）**的根本原因。

## 五、循环不变量：写出零 Bug 边界的“三步验证法”（ALG-05）

写算法最折磨人的就是 `i < n` 还是 `i <= n`、`left < right` 还是 `left <= right`。**循环不变量（Loop Invariant）** 就是你在进入循环前、每轮循环后必须始终守住的“契约”：

1. **初始化（Initialization）**：进入循环第一轮前，不变量就已经成立。
2. **保持（Maintenance）**：假设第 $k$ 轮开始前不变量成立，那么执行完这一轮更新后，第 $k+1$ 轮开始前它**依然成立**。
3. **终止（Termination）**：当循环条件不再满足而退出时，“不变量 + 退出条件”合起来，直接推出我们要的最终答案！

### 实战示范：用不变量写“原地去重（保留最多 1 个）”

需求：升序数组 `nums`，原地删重并返回有效长度。
定义不变量：**`nums[0 .. slow)` 已经严格递增无重复；`fast` 是下一个待检查元素。**
- 初始化：`slow = 0`, `fast = 0` 时，`[0..0)` 为空区间，天然无重复成立。
- 保持：只要 `slow == 0 || nums[fast] != nums[slow - 1]`，就把 `nums[fast]` 放到 `nums[slow]` 再 `slow++`，然后 `fast++`。区间 `[0..slow)` 依然严格递增无重复。
- 终止：`fast == nums.size()` 时退出，所有元素都被检查完毕，有效部分恰好是 `nums[0..slow)`，长度就是 `slow`！

```cpp
int remove_duplicates(std::vector<int>& nums) {
    int slow = 0;
    for (int fast = 0; fast < static_cast<int>(nums.size()); ++fast) {
        if (slow == 0 || nums[fast] != nums[slow - 1]) {
            nums[slow++] = nums[fast];
        }
    }
    return slow;
}
```

## 六、一维与二维前缀和（ALG-06）

**痛点**：给你一个静态数组（或矩阵），后面有 $10^5$ 次询问，每次问“第 $L$ 个到第 $R$ 个数的和是多少”。如果每次现写循环相加，总复杂度 $\mathcal{O}(n \times Q)$ 直接超时。

### 1. 一维前缀和（强烈推荐 1-based 下标！）

定义 `pre[i]` 为前 `i` 个元素的累加和（`pre[0] = 0`）：
$$\text{pre}[i] = \text{pre}[i-1] + a[i-1]$$
任意闭区间 `[l, r]`（0-based 下标，$0 \le l \le r < n$）之和只需 **$\mathcal{O}(1)$ 一次减法**：
$$\text{sum}(l, r) = \text{pre}[r + 1] - \text{pre}[l]$$

```cpp
#include <iostream>
#include <vector>

int main() {
    std::vector<int> a{3, 1, 4, 1, 5, 9};
    int n = static_cast<int>(a.size());
    std::vector<long long> pre(n + 1, 0);
    for (int i = 0; i < n; ++i) {
        pre[i + 1] = pre[i] + a[i]; // 多开1位 pre[0]=0，彻底消灭 l==0 特判！
    }
    // 查闭区间 [1, 4] 即 {1, 4, 1, 5}
    std::cout << "sum[1..4] = " << (pre[5] - pre[1]) << "\n"; // 11
}
```

### 2. 二维矩阵前缀和（容斥原理）

令 `S[r+1][c+1]` 表示从左上角 `(0, 0)` 到 `(r, c)` 的子矩形总和：
- **递推建表**：`S[r+1][c+1] = S[r][c+1] + S[r+1][c] - S[r][c] + mat[r][c]`（左块 + 上块 − 重叠左上块 + 当前格）
- **$\mathcal{O}(1)$ 查询子矩阵 `(r1, c1)` 到 `(r2, c2)`（全闭区间）**：
  $$\text{ans} = S[r_2+1][c_2+1] - S[r_1][c_2+1] - S[r_2+1][c_1] + S[r_1][c_1]$$

**进阶用法（前缀和 + 哈希表）**：问数组中有多少个连续子数组的和恰好等于 `K`？因为 $\text{pre}[j] - \text{pre}[i] = K \iff \text{pre}[i] = \text{pre}[j] - K$，边遍历边用 `unordered_map` 统计历史各前缀和出现次数即可在 $\mathcal{O}(n)$ 解决负数子数组求和！

## 七、差分数组：区间批量加减 $\mathcal{O}(1)$（ALG-07）

**痛点**：航班订票或服务端 QPS 区间统计——连续执行 10 万次操作“把区间 `[L, R]` 里的每一个数都加上 `val`”，最后再问最终数组长什么样。暴力循环每次加都要 $\mathcal{O}(n)$！

**魔法思路（差分是前缀和的逆运算）**：
定义差分数组 `diff`，令 `diff[0] = a[0]`，`diff[i] = a[i] - a[i - 1]`。
- 当你想让原数组闭区间 `[l, r]` **统统加上 `val`**，相邻两项之间的“差值”只有两头变了，中间完全没变！
  - `diff[l] += val;`（从 `l` 开始整体抬高 `val`）
  - `if (r + 1 < n) diff[r + 1] -= val;`（到 `r + 1` 把这段抬高撤销掉！）
- 所有修改结束后，对 `diff` **做一次前缀和还原**，就得到最终数组！每次修改仅 $\mathcal{O}(1)$，总计 $\mathcal{O}(n + Q)$。

```cpp
#include <iostream>
#include <vector>

int main() {
    int n = 5;
    std::vector<int> diff(n + 1, 0); // 多留 1 格防 r+1 越界
    auto add_range = [&](int l, int r, int val) {
        diff[l] += val;
        diff[r + 1] -= val;
    };
    add_range(1, 3, 10); // [0, 10, 10, 10, 0]
    add_range(2, 4, 5);  // [0, 10, 15, 15, 5]

    std::vector<int> res(n);
    int cur = 0;
    for (int i = 0; i < n; ++i) {
        cur += diff[i];
        res[i] = cur;
        std::cout << res[i] << (i + 1 == n ? "\n" : " ");
    }
}
```

## 八、位运算黑魔法与状压基本功（ALG-08）

二进制位运算直接跑在 CPU 单个时钟周期上，在权限掩码、布隆过滤器、哈希位图和状态压缩 DP 里无处不在：

| 表达式 | 作用 | 原理解析 / 示例 |
| --- | --- | --- |
| `(x >> k) & 1` | 读取 `x` 第 `k` 位（0/1） | 把第 `k` 位右移到最低位再用 `& 1` 取出 |
| `x \| (1u << k)` | 把第 `k` 位置 1 | 用无符号 `1u` 移位避免符号位 UB！ |
| `x & ~(1u << k)` | 把第 `k` 位清零 | 除了第 `k` 位是 `0` 其余全 `1` |
| `x ^ (1u << k)` | 把第 `k` 位翻转（0↔1） | 异或 `1` 翻转，异或 `0` 不变 |
| `x & (x - 1)` | **消除最低位的 1** | 用于快速统计 `1` 的个数、判断 `2` 的幂：`x > 0 && (x & (x - 1)) == 0` |
| `x & (-x)` (`lowbit`) | **只保留最低位的 1** | 树状数组（Fenwick Tree）核心操作；补码 `-x = ~x + 1` |
| `a ^ a == 0`, `a ^ 0 == a` | 异或消消乐 | 一组数只有 1 个出现奇数次、其余成对出现，全部异或直接找出它 |

> **致命坑提醒**：永远不要对**有符号负数**做左移 `<<` 或右移 `>>`，也不要写 `1 << 31`（在 32 位 `int` 下属于未定义行为 UB！）；做位掩码一律使用 **`unsigned` / `uint32_t` / `uint64_t`**，右移位使用 `1ULL << k`。C++20 `<bit>` 头文件还提供了 `std::popcount(x)`、`std::countr_zero(x)`、`std::has_single_bit(x)` 等标准化硬件指令包装！

### 练习 1（时间估算）
一个系统要在 1 秒内处理 `n = 200,000` 条日志，以下哪几种算法方案不会超时？
1. 两重嵌套扫描全量对比
2. `std::sort` 后用双指针扫描
3. 遍历一遍使用 `std::unordered_map` 计数

<summary>核对答案</summary>

### 练习 2（前缀和与差分手算）
原数组全 `0`（长度 `n = 4`），依次执行 `diff` 区间加：`[0, 2] + 3` 和 `[1, 3] - 2`。手算 `diff[0..4]` 最终数组并还原原数组。

<details>
<summary>核对答案</summary>

- `[0, 2] + 3`：`diff[0] += 3`, `diff[3] -= 3` -> `diff = [3, 0, 0, -3, 0]`
- `[1, 3] - 2`：`diff[1] -= 2`, `diff[4] += 2` -> `diff = [3, -2, 0, -3, 2]`
- 对 `diff[0..3]` 做前缀和还原得原数组：`[3, 1, 1, -2]`（核对：`[3,3,3,0] + [0,-2,-2,-2] = [3,1,1,-2]`，完全一致！）。

</details>

### 练习 3（位运算纠错）
找出下面这段位掩码代码的隐患并修复：
```cpp
int mask = 0;
mask |= (1 << 31);
```

<details>
<summary>核对答案</summary>

`1` 是有符号 32 位 `int`，在 C++ 中 `1 << 31` 溢出进符号位，属于**未定义行为（UB）**。应改为 `std::uint32_t mask = 0; mask |= (1u << 31);`（或用 `1ULL << k`）。

</details>
