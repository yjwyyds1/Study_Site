# 计算机组成 (MACH)

[课程总览](../course-outline.md) · [默认路线](route.md) · [实验与验收](logscan.md)

以 Linux x86-64、C++20 和 System V AMD64 ABI 为实验基线。先用字节断言保证正确，再读汇编解释现象，最后测量。各章结果均为预期验收，Linux 实测由学习者记录。

## 第一篇 数据表示与二进制边界

### 数值与编码

- 入口：从基本 C++ 表达式进入。
- 能力：解释数值、位模式与跨端格式的对应关系。
- 检验：提交边界值表、十六进制夹具和往返断言。

<a id="mach-01"></a>

#### MACH-01 整数表示与溢出

- 先修：[CPP-02](cpp.md#cpp-02)
- 层级：入门（核心基础）
- 状态：待编写
- 问题：为何计数回到零，而有符号溢出不能按回绕推断？
- 小节
  1. 固定位宽与二进制补码
  2. 无符号模运算及有符号范围
  3. 整数提升与转换前范围检查
- 能力：能以宽类型和边界判断保护计数。
- 练习与预期：用 uint32_t 最大值加一观察 0；对 int32_t 最大值做加一前检查并拒绝。
- 项目或独立实验：独立实现带边界检查的日志条数累加器。
