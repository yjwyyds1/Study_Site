# 操作系统 (OS)

[课程总览](../course-outline.md) · [默认路线](route.md) · [实验与验收](logscan.md)

以 C++20/Linux 小程序验证操作系统模型。运行结果需保留命令、输入、输出及内核版本；以下练习给出预期。Linux 命令和接口实操可跨读 [Linux 课程](linux.md)。

## 第一篇 执行、协调与地址空间

### 执行实体与 CPU 调度

- 入口：能构建小程序并在 Linux 终端运行。
- 能力：区分请求内核、创建执行实体和调度 CPU 的路径。
- 检验：提交系统调用、退出状态和线程状态三份记录。

#### OS-01 用户态、内核态与系统调用

- 先修：[CPP-02](cpp.md#cpp-02)
- 层级：入门（核心基础）
- 状态：部分覆盖，[Linux 正文](../../src/content/handbook/linux-process-io.md)展示 open 和 strace，待补特权边界、封装与调度区别。
- 问题：程序如何请求打开文件，何时会进入内核？
- 小节
  1. 用户态与内核态的权限边界
  2. 库封装、系统调用与错误返回
  3. 模式切换与调度切换
- 能力：能从调用及返回值解释一次资源请求。
- 练习与预期：在临时目录重跑第一天的 hello，核对退出 0。再编译运行 Linux 正文的 fd_demo；首次使当前目录没有它打开的 `test.txt`，核对 ENOENT 与退出 1。写入 `INFO ready` 加换行后重跑，核对读到 11 字节与退出 0。用 [LNX-06](linux.md#lnx-06) 的 strace 补取内核返回证据。
- 项目或独立实验：复用 Linux 正文的 fd_demo，标出库调用与内核追踪行。
