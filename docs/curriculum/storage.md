主线从文件格式和持久化错误进入 SQLite，先交付可查询的 LogScan v2 本地归档，再用 WAL 与重启实验证明 v3 可采用的存储确认语义。

[项目链与验收](../course-method.md)从 [v0 单文件统计](../../src/content/labs/logscan.md)、[v0.1 多文件工程](../../src/content/labs/logscan-build.md)进入 v1 多文件聚合计划、v2 本地归档计划和 v3 TCP 服务计划。[旧题名为 v2 的服务指导页](../../src/content/labs/logscan-service.md)可跨读其存储接口和综合验收设计。服务相关单项源码只有[分帧](../../public/examples/network-framing.cpp)与[队列](../../public/examples/concurrency-queue.cpp)，SQLite 示例内嵌于正文。

#### DB-04 表结构、约束与 SQL 查询

- 先修：[DB-01](#db-01)
- 层级：入门（基础）
- 状态：部分覆盖，[SQLite C++ API、索引与事务回滚](../../src/content/handbook/storage-sqlite.md)有单表建表、插入和过滤示例，关联、排序与约束练习待编写。
- 问题：如何按来源统计 ERROR，并保留每条记录的身份？
- 小节
  1. 导入批次与日志表、主键、外键与唯一约束
  2. SELECT、WHERE、ORDER BY、COUNT 和 GROUP BY
  3. JOIN、NULL 与空字符串，连接上启用外键检查
- 能力：能设计批次表与记录表，并写出结果顺序稳定的查询。
- 练习与预期结果：批次 A 写 2 条 ERROR，B 写 1 条 INFO；聚合结果应为 A 的 ERROR 2；建表时用 `FOREIGN KEY(batch_id) REFERENCES batches(id)`（batches.id 为主键）；在连接中启用 `PRAGMA foreign_keys=ON` 并查询该设置确认返回 1，插入不存在的批次 ID 应触发约束。
- 项目或独立实验：在临时数据库提交建表 SQL、固定种子数据及预期查询表。
