# C++ 研习手册：课程总览

课程以 C++20 为基线，面向 Linux 上的通用 C++ 工程开发。初学可用 Windows PowerShell 与 MinGW，或直接在 Linux/WSL 开始。每次先预测结果，再运行、解释、修改和验证。一个 LogScan 项目贯穿各阶段。

**第一次打开本站，从[默认路线的第一天](curriculum/route.md#第一天)开始。** 安装工具、确定当前目录、构建第一个程序之后再进入 v0。遇到具体问题时用下表跳入学科，做完章节练习再回到[项目验收](curriculum/logscan.md)。

| 学科 | 从什么开始 | 学到哪里 |
| --- | --- | --- |
| [现代 C++](curriculum/cpp.md) | C++20 环境和最小程序 | 资源归属、泛型接口与标准库 |
| [工程工具链](curriculum/engineering.md) | 终端、文件和工作目录 | 可重复构建、测试、CI 与发布 |
| [数据结构与算法](curriculum/algorithms.md) | 复杂度与循环不变量 | 标准库选型、图与搜索、Top-K |

| [Linux 实践](curriculum/linux.md) | Shell 和目录 | 系统接口、跟踪、事件循环和服务管理 |

| [存储与数据库](curriculum/storage.md) | 文件格式与写入失败 | SQL、SQLite、事务、索引与恢复 |

各学科使用稳定的章节号。补修时先查章节的直接先修，再沿链接递归补齐。标为「已有正文」的条目可打开原稿，其中的补写范围在条目里说明。「待编写」提供写作设计和练习契约。「已有实验」区分指导页、单项源码与完整参考工程，按验收页记录的范围执行。已有文章 URL 和学习记录编号继续使用。

## 站点导航与使用提示

本地启动站点（`npm run dev`，默认地址 `http://127.0.0.1:4321`）后，按以下页面推进学习：

- **[开始学习](/):** 查看继续阅读入口、当前待复习项与近期可做的实验。
- **[课程大纲](/handbook/):** 浏览全部课程阶段、已发布章节与知识地图。
- **[项目实验](/labs/):** 进入 LogScan 等动手实验指导页与验收要求。
- **[学习记录](/records/):** 记录验收依据、管理本地学习档案、导出复盘与备份。

左侧「完整课程目录」支持在**全部**与**仅看可学**之间切换，并通过章节编号前的状态圆点区分「已有正文 / 已有实验」「部分覆盖」与「待编写」；按 `Ctrl K` 可随时全站搜索。
